# dsh-price-badge

DeepSeek 峰谷费用时段徽章 —— 在 DeepSeek Harness Web 右下角悬浮显示当前处于**高峰**还是**空闲**时段，点击展开**官方人民币价格表**（deepseek-v4-flash / deepseek-v4-pro），帮你挑省钱时段。

## 功能

- 右下角常驻徽章，每 60 秒自动刷新：
  - 🟢 空闲时段：「现在：空闲 · 5折」（价格 = 高峰一半）
  - 🟠 高峰时段：「现在：高峰 · 全价」
  - 🔵 生效前：「8/17 起峰谷定价 · 空闲5折」（预告，避免误导）
- 点击展开卡片：
  - 高峰时段（北京时间）：9:00–12:00、14:00–18:00；其余为空闲时段
  - 生效时间：2026-08-17 00:00（北京时间）起
  - 官方人民币价格表（元 / 百万 tokens），模型列悬停显示完整模型名
- 配色跟随 DSH 深浅主题，不挡操作

## 价格表（官方人民币定价）

| 模型 | 时段 | 输入·缓存命中 | 输入·未命中 | 输出 |
|---|---|---|---|---|
| deepseek-v4-flash | 空闲 | ¥0.05 | ¥1.5 | ¥4.5 |
| deepseek-v4-flash | 高峰 | ¥0.10 | ¥3.0 | ¥9.0 |
| deepseek-v4-pro | 空闲 | ¥0.15 | ¥4.5 | ¥13.5 |
| deepseek-v4-pro | 高峰 | ¥0.30 | ¥9.0 | ¥27.0 |

## 安装

```sh
dsh plugin --profile web add github:Zevvvv1/dsh-price-badge
```

安装后**重启 DSH 服务器**，刷新页面即可看到右下角徽章。

## 修改价格 / 时段

编辑 `lib/client.js` 顶部的 `MODELS`（价格）与 `WINDOWS`（高峰时段）常量。
