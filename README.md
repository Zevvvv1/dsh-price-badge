# dsh-price-badge

DeepSeek 峰谷费用时段徽章 —— 在 DeepSeek Harness 右下角悬浮显示当前处于**高峰**还是**空闲**时段，点击展开**官方人民币价格表**（`deepseek-flash` / `deepseek-v4-pro`），帮你挑省钱时段。

## 功能

- 右下角常驻徽章，每 30 秒自动刷新（从后台切回页面时也会立即刷新）：
  - 🟢 空闲时段：「现在：空闲 · 5折」（价格 = 高峰一半）
  - 🟠 高峰时段：「现在：高峰 · 全价」
- 点击展开卡片：
  - 当前北京时间与星期
  - **距离下次峰谷切换的倒计时**
  - 高峰时段规则与空闲时段规则说明
  - 官方人民币价格表（元 / 百万 tokens），模型列悬停显示完整模型名与版本
  - 节假日表过期时的醒目告警
- 配色跟随 DSH 深浅主题，不挡操作

## 峰谷时段判定

依据官方定价页口径：**北京时间周一至周五（不含中国法定节假日）9:00–12:00、14:00–18:00 为高峰时段；其余时段，包括周末及中国法定节假日全天均为空闲时段。** 空闲价格为高峰的一半。

实现上据此做了三条判定，缺一不可：

| 情况 | 判定 | 说明 |
|---|---|---|
| 周六、周日 | 空闲 | 周末全天空闲 |
| 中国法定节假日 | 空闲 | 见 `HOLIDAYS` |
| 法定调休上班日 | **按工作日参与峰谷判定** | 见 `MAKEUP_WORKDAYS`，官方口径「不含法定节假日」指的是节假日当天，调休日属法定工作日 |

## 安装

作为插件加入当前 profile（`<本地检出目录>` 换成本仓库的绝对路径）：

```sh
dsh plugin --profile web add <本地检出目录>
```

或直接用 `plugin_manager` 工具：

```
plugin_manager { action: "install_bundle", target: "<本地检出目录绝对路径>" }
```

浏览器半点会被 `dsh-client-hmr` 轮询热替换，**无需重启**；刷新页面即可看到右下角徽章。

## 修改价格 / 时段

编辑 `lib/client.js` 顶部的常量：

| 常量 | 用途 |
|---|---|
| `PRICING_LABEL` | 价格口径的展示用日期（当前口径已生效，故不再维护"生效前"状态） |
| `PEAK_WINDOWS` | 高峰时段（北京时间，分钟数区间） |
| `HOLIDAYS` | 中国法定节假日（全天空闲） |
| `MAKEUP_WORKDAYS` | 法定调休上班日（按工作日判定） |
| `CALENDAR_VALID_TO` | 节假日表有效期上界，超出后卡片显示告警 |
| `MODELS` | 各模型空闲/高峰三档价格 |

## 验证

```sh
node tools/selfcheck.mjs
```

18 条断言：工作日边界、周末误判、法定节假日、调休上班日、以及下次切换计算。

## 已知限制

- **节假日表需要逐年更新。** 国务院一般在上一年 11 月发布次年放假安排。当前表覆盖 2026 年，上界写在 `CALENDAR_VALID_TO`；超出后卡片会显示告警，且此时「法定节假日全天按空闲计价」这一条会退化为按周末规则判断。
- **月历只识别法定节假日，不识别临时调休**（如遇重大活动临时调整放假，需手工更新 `MAKEUP_WORKDAYS`）。
- 模型名 `deepseek-flash` 按官方说明同时覆盖旧名 `deepseek-v4-flash` 的请求。
